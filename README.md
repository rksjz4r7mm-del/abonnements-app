# Mes abonnements (étape 1)
Application web installable (PWA). Aucun serveur, aucun compte, 0 €.
Lancer en local : `python3 -m http.server 8000` puis http://localhost:8000
Tests : `node test.js` (logique) et `node e2e.js` (navigateur, nécessite Playwright).
Après toute modification des fichiers, change `abos-v1` en `abos-v2` dans sw.js pour que les téléphones se mettent à jour.
